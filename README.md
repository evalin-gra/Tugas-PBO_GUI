## Komponen GUI

Program ini menggunakan lima komponen utama GUI, yaitu:

| Komponen         | Fungsi                                             |
| ---------------- | -------------------------------------------------- |
| **JLabel**       | Menampilkan judul dan keterangan pada form.        |
| **JTextField**   | Menerima input nama pembeli.                       |
| **JRadioButton** | Memilih satu budget buket dari beberapa pilihan.   |
| **JCheckBox**    | Memilih satu atau lebih jenis bunga.               |
| **JButton**      | Menjalankan proses pemesanan melalui tombol ORDER. |
